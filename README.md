# AI Security Hub

Build the frontend foundation for a professional cybersecurity web application called "AI SECURITY MESH".

IMPORTANT:

This is FRONTEND ONLY for now. Do not implement backend, real AI models, database, authentication logic, APIs, cloud storage, or fake working security scans. Use realistic demo/mock data only where UI needs sample content, and clearly structure the code so real services can be connected later.

PROJECT PURPOSE:

AI SECURITY MESH is an AI-powered cybersecurity platform designed to help users detect scams, phishing URLs, suspicious messages, fake websites, malicious files, and weak passwords.

For this first version, create a polished responsive LANDING PAGE that introduces the product and its major security modules.

DESIGN:

- Professional modern cybersecurity SaaS design.

- Clean premium UI.

- Use a dark navy/deep blue cybersecurity visual identity with subtle cyan/blue/purple accents.

- Avoid an overly flashy gaming-style design.

- Use clear typography, strong spacing, rounded cards, subtle gradients, and professional security icons.

- Make the page responsive for desktop, tablet, and mobile.

- Create a consistent reusable design system for future pages.

LANDING PAGE SECTIONS:

1. Navbar

   - AI SECURITY MESH logo/name

   - Features

   - How It Works

   - Security

   - About

   - Login button

   - Get Started button

2. Hero Section

   - Heading: "Your Intelligent Digital Security Layer"

   - Supporting text explaining that AI SECURITY MESH helps analyze suspicious digital content and provides understandable security guidance.

   - Primary CTA: "Get Started"

   - Secondary CTA: "Explore Features"

   - Add a professional cybersecurity visual such as a shield/security mesh illustration.

   - Include subtle animated background elements.

3. Security Modules

   Create cards for:

   - Scam Message Detection

   - Phishing URL Detection

   - Fake Website Identification

   - Malicious File Analysis

   - Password Strength Analysis

   - AI Cybersecurity Assistant

   - Personal Security Score

   - Security Reports & Alerts

4. How It Works

   Show a simple 4-step visual flow:

   Input → Analysis → Risk Assessment → Recommendations

5. Why AI SECURITY MESH

   Include concise benefits:

   - Multi-layer threat analysis

   - Understandable security results

   - Risk scoring

   - Security history

   - Actionable recommendations

6. Security Architecture Preview

   Show a simple visual representation of:

   User Input → Preprocessing → AI Analysis → Risk Fusion → Recommendation → Dashboard

7. Final CTA

   - "Start Protecting Your Digital Life"

   - Get Started button

8. Footer

   - Product

   - Security

   - Resources

   - Contact

   - Privacy

   - Terms

INTERACTION AND ANIMATION REQUIREMENT:

I specifically want polished UI effects throughout the website.

- Buttons must have subtle shadows.

- Buttons should have smooth hover animations.

- On click/press, buttons should have a slight 3D/depth effect, as if the button is being physically pressed.

- Cards should have subtle shadows and smooth hover elevation.

- Cards can slightly lift on hover.

- Use smooth transitions and professional micro-interactions.

- Icons and important UI elements may have subtle hover animations.

- Use tasteful entrance/reveal animations when sections enter the viewport.

- Keep animations smooth, subtle, and professional.

- Do NOT make the website overly flashy.

- Respect prefers-reduced-motion where practical.

CODE QUALITY:

- Use reusable React components.

- Keep components organized and maintainable.

- Use semantic HTML and accessible controls.

- Ensure keyboard focus states are visible.

- Do not hardcode repeated UI unnecessarily.

- Keep the architecture ready for adding the dashboard, scan center, authentication, AI modules, backend APIs, and database later.

IMPORTANT:

Do not claim that any security detection is actually working yet.

This stage is only the frontend foundation and landing page.
